# 삼성전자 다음 거래일 종가 예측

100거래일 종가 입력을 지원하는 정적 웹앱과 재현 가능한 종가 전용 모델 비교 실험입니다.

## 실행

Python 3.12 기준:

```sh
pip install -r requirements.txt
python train.py --as-of 2026-10-08
python verify.py
python -m http.server 8000 --directory docs
```

http://localhost:8000 에서 대시보드를 엽니다. `--refresh`로 Yahoo 데이터를 다시 받을 수 있습니다. 기본 실행은 저장된 원본 응답으로 재현합니다. `--as-of` 당일 및 이후 봉은 제외합니다.

## 방법

- 삼성전자 보통주 005930.KS, Yahoo 원종가(Close). 2018년 액면분할 이후부터 사용합니다. 수정종가, 거래량, 뉴스는 사용하지 않습니다.
- 5/20/60/100/250개의 연속 거래일 종가를 각 창 내부의 수익률(w-1개)로 변환하여 다음 거래일 수익률을 예측합니다. 마지막 종가 × (1 + 예측 수익률)이 예측 종가입니다.
- Ridge(StandardScaler 포함)와 Random Forest, 전일 종가 유지 기준을 비교합니다.
- 동일한 날짜 집합(250일 이력이 있는 날)으로 비교합니다. 검증 2024·2025년, 확장 학습. Ridge alpha는 1/100/10000. RF는 160 trees, depth 5, min leaf 25, seed 42.
- 2026년은 테스트로만 사용합니다. 검증 MAE로 모델/창을 선택한 뒤 2025년까지 재학습하여 고정합니다. 2026년 매일 직전일까지의 실제 종가를 입력하는 one-step 평가입니다. 학습/스케일링/모델 선택에는 테스트 데이터를 쓰지 않습니다.
- 경험적 범위는 검증 상대 절대 오차의 90백분위. 미래 포함률 보장 없음.
- 방향 일치율은 예측 변화와 실제 변화의 부호 일치율(보합 포함). 전일 유지 기준은 보합만 맞힙니다.
- 2026년 미래/미확보 날짜는 평가하지 않습니다. 데이터 공급자 수정 가능성이 있어 원본 및 해시를 함께 보관합니다.

## 파일

`train.py`: 다운로드, 학습, 검증, 평가, 브라우저 모델 직렬화. `verify.py`: 시간 경계 및 브라우저 추론 동등성 검사. `data/yahoo.json`: 원본 응답. `data/close.csv`: 사용 데이터. `docs/`: GitHub Pages 정적 앱, 모델, 평가 결과. 모델 추론은 브라우저에서 실행됩니다.

## 배포

GitHub Pages 설정을 GitHub Actions로 선택하면 main push 시 `.github/workflows/pages.yml`이 docs 폴더를 게시합니다. 기존 결과를 배포하므로 학습 데이터는 배포 중 자동으로 바뀌지 않습니다.

예측은 연구용이며 투자 수익을 보장하지 않습니다.
